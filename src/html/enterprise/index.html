RECOMMENDED Refurb to Grade A — highest-margin path. £29 additional per device vs. the next-best path (Grade B), £47 vs. the default "Sell as-is." Across 200 devices with this profile in the PO, that's £9,400 additional margin captured vs. the default routing.

VAT treatment (HMRC VATMARG02300): Margin scheme applies to the device only — VAT charged on the device margin, not the full sale. Parts are handled under standard VAT: input VAT reclaimable when purchased, but parts cost cannot be added to the device's margin-scheme cost basis. Many refurbishers get this wrong and get audited. GSX Provenance evidences the correct split per device. Provenance

Finance-risk flagging + VAT margin scheme evidence.

Verifies original retailer, first-activation date, country of first sale and warranty status. Two audit trails from one check: silent-blacklist finance-risk on UK-sold devices, and margin-scheme eligibility on imported stock (post-Brexit the EU no longer counts). Feeds Flow's routing rules so high-risk stock auto-routes accordingly and Pricer prices for the correct VAT treatment.

  • 9-field per-IMEI provenance report
  • Grey-import + finance-risk + margin-scheme flags

  • REST API for bulk-batch checks; feeds Flow & Pricer
